# The Hold

Whoever is named here edits the current documents directly and writes no worklog entries; everyone else writes their worklog. One person at a time. Take it: pull, check the table is empty, add your row, commit and push this file alone. Release it: commit and push your edits, empty the table, push. `/sync-worklogs` takes it for the length of the sync.
